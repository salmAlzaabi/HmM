# HmM — موقع شبكة السيرفرات

موقع ستاتيك (بدون بوت، بدون سيرفر خلفي) يعرض سيرفرات ديسكورد التابعة لك: صورة السيرفر، اسمه، نوعه، وعدد الأعضاء + المتصلين الآن، محدّثين تلقائياً.

## كيف تشتغل الأعداد بدون بوت؟

ديسكورد يوفر endpoint عام لأي رابط دعوة:
`https://discord.com/api/v10/invites/{code}?with_counts=true`

يرجّع اسم السيرفر، صورته، وتقريب لعدد الأعضاء/المتصلين — بدون توكن أو بوت. المتصفح ما يقدر يناديه مباشرة (ديسكورد يمنع CORS)، فحليت الموضوع بـ **GitHub Action** يشتغل كل 30 دقيقة، يجيب البيانات، ويحدّث ملف `data/live.json` تلقائياً. الموقع نفسه HTML/CSS/JS عادي يقرأ هذا الملف.

## الخطوات

1. **عدّل `data/servers.json`**: لكل سيرفر حط `inviteCode` (كود الدعوة، مثلاً من `discord.gg/abc123` الكود هو `abc123`)، والاسم، النوع، والوصف.
2. **ارفع المجلد على GitHub**: أنشئ repo جديد وارفع كل الملفات كما هي.
3. **فعّل GitHub Pages**: من Settings → Pages → Deploy from branch → اختر `main` والمجلد `/ (root)`.
4. **فعّل الـ Action**: أول مرة روح لتبويب Actions → اختر "تحديث بيانات السيرفرات" → Run workflow يدوياً عشان يجيب البيانات أول مرة، بعدها راح يشتغل تلقائياً كل 30 دقيقة.
5. خلاص، الموقع شغال على `https://username.github.io/repo-name/`.

## إضافة سيرفر جديد

انسخ ولصق كائن جديد داخل `data/servers.json`:

```json
{
  "id": "unique-id",
  "name": "اسم السيرفر",
  "type": "RP",
  "typeLabel": "رول بلاي",
  "description": "وصف قصير عن السيرفر.",
  "inviteCode": "كود-الدعوة",
  "fallbackIcon": ""
}
```

- `id`: أي نص فريد (يُستخدم للربط بين الملفين).
- `fallbackIcon`: رابط صورة احتياطية تظهر إذا فشل الجلب التلقائي (اختياري).

## ملاحظات

- إذا كانت الدعوة منتهية أو غير صحيحة، البطاقة تظهر بدون أعداد وزر "غير متاح حالياً" بدل الانضمام.
- تقدر تغيّر مدة التحديث من `.github/workflows/update-servers.yml` (قيمة `cron`).
- التصميم والألوان في `assets/style.css`، والمنطق في `assets/script.js` — كله عادي HTML/CSS/JS بدون أي framework.
